# Funngro Two-Page Website Concept

A responsive, two-page website concept for the Funngro task:
- `index.html` — For Teens
- `companies.html` — For Companies
- `style.css` — shared responsive styling
- `script.js` — mobile navigation and FAQ interactions

## Run locally
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension and click **Go Live**.
4. Use the top navigation to move between the two pages.

No build tools or package installation are required.

## Deploy free with Vercel
1. Create a GitHub repository and upload these files to the repository root.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository.
4. For a static HTML site, leave the framework preset as **Other** and do not add a build command. The output directory can remain blank or `.`.
5. Deploy and test both pages on mobile and desktop.
